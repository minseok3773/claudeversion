# 자동 검사(시험)

이 폴더의 시험은 프로그램을 고칠 때 이미 되던 기능이 망가지지 않았는지 확인합니다.

- **가상 자료만 씁니다.** 실제 회원 이름·상담일지·기관 문서는 들어 있지 않습니다(회원 이름은 ‘회원 001’처럼 씀).
- **실제 Gemini·인터넷에 접속하지 않습니다.** Gemini·구글 검색·논문 검색의 응답은 모두 가짜로 만들어 씁니다. API 키도 필요 없습니다.
- 이 폴더와 `.github` 폴더는 Vercel 사이트에 올라가지 않습니다(`.vercelignore`).

## GitHub에서 자동으로 확인

`main`에 올릴 때마다 GitHub Actions가 모든 시험을 돌립니다(`.github/workflows/tests.yml`).
저장소의 **Actions** 탭에서 결과를 볼 수 있습니다. 초록색 ✓는 모두 통과, 빨간색 ✗는 실패한 시험이 있다는 뜻이고,
실행 기록을 누르면 시험별 결과 표가 나옵니다. Actions 화면의 **Run workflow** 버튼으로 직접 돌릴 수도 있습니다.

## 컴퓨터에서 직접 돌리기 (Node.js 20 이상)

```bash
npm ci --ignore-scripts
npm install --no-save --ignore-scripts jsdom@24.1.3
npm test                         # 전부
node tests/run-all.js t66 t64b   # 이름으로 골라서
```

컴퓨터가 느려 우연히 실패하는 경우를 걸러 내려고, 실패한 시험은 한 번 더 돌려 봅니다.
날짜 계산이 같도록 한국 시간(Asia/Seoul)으로 돌립니다.
